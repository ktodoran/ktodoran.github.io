ParkPro Founder and engineer

ParkPro is a B2B SaaS platform for travel agencies that specialize in Walt Disney World. Agents use it to manage clients and trips and to build day-by-day park itineraries, and their travelers get the finished plan in a mobile app on iOS and Android. I designed the architecture, wrote the code and operate it in production.

Visit parkproit.com

What I built

Itinerary engine
A rule-based engine that turns external park data and each trip’s scheduling requirements into a day-by-day plan. Rules keep the output explainable, and the agent can change any of it.
Background processing
Third-party API integrations, automated data ingestion and scheduled jobs, run asynchronously through job queues.
AI inside the workflow
OpenAI is integrated into the screens agents already use, not added as a separate chatbot. The system proposes and the agent approves.
Infrastructure as code
AWS infrastructure defined in CloudFormation and CDK, covering EC2, Aurora, S3, SES and CloudWatch.
Testing and delivery
CI/CD pipelines with automated unit and integration tests. I plan, implement and test with Cursor coding agents, with the test suite as the check.
Operations
I own database migrations, deployments, production on-call and incident resolution.
